| Option | Description | Example |
|--------|-------------|---------|
| `--wset-rvrt TIME` | W setpoint reversion | `--wset-rvrt 5m` |
| `--varset-rvrt TIME` | VAR setpoint reversion | `--varset-rvrt 300s` |
| `--vaset-rvrt TIME` | VA setpoint reversion | `--vaset-rvrt 1h` |
| `--rvrt-all TIME` | Set all reversion timers | `--rvrt-all 10m` |
